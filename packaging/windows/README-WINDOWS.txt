Square Photo Padder — Windows x86-64
===================================

To run
------
Extract the entire ZIP, then double-click Square-Photo-Padder.exe.
Keep _internal and the other bundled files beside the executable.
No Python installation or administrator rights are required.

Unsigned download notice
------------------------
This package is not code-signed. Windows may show a SmartScreen warning.
Use only the Studio download linked on the official website and compare its
published SHA-256 hash. Do not bypass a warning for an unexpected download,
a mismatched checksum, or an app whose source you do not trust.

Photos and settings
-------------------
Photos are processed locally. Outputs are high-quality JPEGs, not lossless
masters. Numbered-copy mode preserves originals by default. Back up photos
before deliberately enabling Overwrite. User-scope settings remember the
last selected folder, appearance and optional watermark text.
