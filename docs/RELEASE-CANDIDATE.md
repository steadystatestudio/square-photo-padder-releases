# Release candidate

Square Photo Padder 1.4.3 adds independent desktop appearance providers and saved font/accent overrides without requiring system Python or PyGObject on Linux. Ordinary settings/color forms are fitted; the main window reserves meaningful preview space using measured control sizes.

Validate exact Windows ZIP and AppImage packages at default and enlarged fonts, separate display scaling, light/dark appearance, and multiple accents. Check keyboard choice controls, small monitors, restored geometry, photo export and preservation. See the private release evidence for package hashes, source revision and actual platform results; source tests alone do not establish packaged desktop matching.
