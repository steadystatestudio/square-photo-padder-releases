Square Photo Padder — Linux x86-64

Built for Ubuntu 22.04 and verified on Ubuntu 24.04. Other distributions are
not guaranteed. No Python installation is needed.

AppImage: make Square-Photo-Padder-x86_64.AppImage executable and launch it.
Without FUSE: APPIMAGE_EXTRACT_AND_RUN=1 ./Square-Photo-Padder-x86_64.AppImage
Alternatively extract the .tar.gz and run square-photo-padder/square-photo-padder.

If a desktop library is missing, review LINUX-SYSTEM-DEPENDENCIES.json inside
the portable archive. It lists Ubuntu package prerequisites and an install command.

The app processes photos locally. JPEG outputs are saved beside originals.
Safe copy mode is the default. Keep backups before deliberately overwriting.
See README.md, THIRD_PARTY_NOTICES.md and LIBRARY-REPLACEMENT.txt.
